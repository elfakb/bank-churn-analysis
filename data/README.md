# Data

Download **Credit Card Customers** from Kaggle and place the file here as `BankChurners.csv`:
https://www.kaggle.com/datasets/sakshigoyal7/credit-card-customers

The file is not committed to this repository (see `.gitignore`); please check the dataset's licence on Kaggle.

Veri setini Kaggle'dan indirip bu klasöre `BankChurners.csv` adıyla koyun (yukarıdaki bağlantı). Dosya repoya eklenmemiştir.
